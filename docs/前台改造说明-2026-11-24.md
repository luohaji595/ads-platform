# 前台改造说明（2026-11-24）

对应提交：`feat(web): 审批台拆解与驾驶舱重构（零依赖 React 18）`

改造依据是 `adsdesk_ui_react_18.html` 那份方案（1213 行审批台 → 高密度 10 分钟作业流）。
硬约束：**不加任何第三方依赖**。`adsdesk/web/package.json` 的 dependencies 仍然只有
`react` + `react-dom`，没有 Tailwind / AntD / ECharts，图表仍是手写 SVG。

---

## 一、为什么要改（改之前的真实毛病）

| 症状 | 代码层面的原因 |
|---|---|
| 切到驾驶舱再切回审批台，筛选、滚动位置全丢 | `App.tsx` 用 `{tab === 'approval' && <Approval/>}` 条件渲染，切走即卸载 |
| 浏览器后退键不起作用 | 每次切 Tab 都 `history.replaceState`，历史里永远只有一条 |
| 每切一次 Tab 多打一次 `/meta/freshness` | 取新鲜度的 `useEffect` 依赖是 `[tab]`，切页就重跑 |
| 改一条价要在 1213 行里翻三个地方 | 奏折阅读、审批按钮、执行单勾选、内联样式全缠在一个文件 |
| 执行单里的「已改」会撞 409 | 那个按钮只判 `it.executed_at`，不看决策 `status` |
| 驾驶舱宽屏大量留白、窄屏挤成一团 | 三张折线图写死 `width={720}` 像素 |
| 窗满那天来看归因，结果是空的 | 只显示「归因至 X 日」，没说明「还要等报表回传 3 天」 |

---

## 二、改了什么

### Phase 1 · 导航与状态机

- 四个视图改成**常驻挂载**，用 `hidden` 属性保活：切走不卸载，切回来 DOM 还在。
- `pushState` + `popstate` 监听：后退键真的能退回上一个 Tab，URL 里的 `?tab=` 可分享。
- 数字键 `1`–`4` 切页（`title` 里有提示）；输入框 / textarea / contentEditable 里打字不触发。
- 顶栏新增两个徽章：「N 条策略待认领」「N 条反对待兑现」，点进 Agent 页；有计数时对应 Tab 上加小圆点。
- **接口版本自检**：后端 `/api/health` 返回 `api_version`，前端 `lib/api.ts` 里写 `EXPECT_API`，
  两边不等时顶栏红字直说「前端要 v3、后端在 v2」——单人项目最贵的失败方式是改完前端忘了 build。
- 连不上后端时给一条可照做的提示（起服务的命令），不再是一页空白。

### Phase 2 · 1213 行拆成 1 + 9

`src/pages/Approval.tsx` **1213 → 389 行**，只保留状态、请求与编排。渲染分到 `src/pages/approval/`：

| 文件 | 行数 | 职责 |
|---|---|---|
| `shared.tsx` | 177 | 富文本、枚举映射、`gateText`、`suppressedWhy`、`attrProgress` |
| `ObservingCard.tsx` | 206 | 观察中 / 证据不足待你定（含强制批准与理由输入） |
| `SuppressedCard.tsx` | 83 | 被拦下的条目，按原因分组 |
| `AgentCard.tsx` | 201 | 诊断 agent 的四个问题 |
| `ConclusionCard.tsx` | 98 | 今日结论、最贵三笔、账户级告警 |
| `QuestionsCard.tsx` | 115 | 需要你判断的问题（勾选 / 划掉 / 跳过） |
| `DecisionRow.tsx` | 98 | 单条决策卡片 + 严格状态机按钮 |
| `ExecOrderCard.tsx` | 158 | 执行单：生成、进度、复制、逐条标已改 |
| `SideCards.tsx` | 56 | 结构冲突 / 分层证据 / 数据新鲜度 |

右栏改 `.sticky-rail` 粘性跟随 —— 批十几条要往下滚着抄数字时，执行单不再跑掉；窄屏（≤1080px）自动退回静态。

执行单补了三件原本缺的事：

1. **409 闸门**：非 `approved` 的条目不渲染「已改」按钮，改显示「当前状态「proposed」，这条要先批才能标已改」。
   原来那个按钮只判 `executed_at`，点了必然 409。
2. **进度条** `已改 3/7`，全完成显示「这张单做完了」；用渲染时现算，不另存 state，否则点完不动像没生效。
3. **复制**：整单复制清单（贴进飞书 / 备忘）+ 每条单独复制（后台按活动名搜索时用）。

另加 `提交全部（N）`：一次提交所有打好的钩，走 `POST /api/approve/batch`（后端整批一个事务，
失败文案明说「整批回滚，一条都没写」）。只提交与当前状态不同的条目 —— `load()` 已把
approved/rejected 预填进 `marks`，全量提交会白刷 `checked_at`。

### Phase 3 · 驾驶舱与 Agent 闭环

- **折线图全部改 `viewBox` 自适应**，废弃写死 `W=720`；`preserveAspectRatio` 默认等比，文字不变形。
- **末段未成熟区**：最后 2 天画灰色带 + 虚线分隔，`<title>` 说明「报表还在回传归因，这几天不进判断」。
  横轴步长按「已结算天数 + 未成熟天数」算，否则最后一天会紧贴右边框，看不出还有两天没结算。
- **hover 标尺**：每个数据点覆盖透明 `<circle r=5>`，原生 `<title>` 显示「日期 + 数值」，零 JS。
- **遇 `null` 断线**，不再一条线跨过缺口 —— 跨过去等于替缺数据的那几天编了个值。
- **KPI 六格 → 七格网格**：花费 / 销售额 / ACOS / **ROAS** / CVR / CPC / 待处理。ACOS 超 35% 那格变红并写「高于 35%」。
- **ACOS 与 CVR 两列并排**（Small Multiples，`viewBox 0 0 360 84`）：同一天的两个数该一起进眼睛。
- **归因两段式进度**（`shared.tsx: attrProgress`）：
  `窗口第 4/7 天 → 归因回填缓冲中（剩 2 天） → 窗口已满（X 日）· 等引擎回看`。
  原来只写「归因至 X 日」，人到满窗那天来看是空的，会以为系统没跑。
- **Agent 页新增「待认领策略」卡**：认领（以后按这个来）/ 驳回，空态写清为什么空。
- **反对表加「最近 / 按到期日」切换**：按到期日时后端 `sort=due` 排序（35 条反对里 26 条没写兑现日，
  前端只能排已返回的 20 条，最近到期的那几条可能根本没进来）；已过兑现日但未判定的给一条黄条提醒。

### 后端配套

| 文件 | 改动 |
|---|---|
| `api/routes/policy.py`（新增 216 行） | `GET /pending`、`GET /active`、`POST /{id}/activate`、`POST /{id}/reject`。只允许 `proposed → active/rejected`；重复点返回 `noop` 不刷时间戳；生效中想悄悄改内容直接 409；note 以「· 谁 哪天：内容」追加进 `evidence_text` |

| `api/routes/agents.py` | `/objections` 加 `sort=recent|due` |
| `web/index.html` | 内联空 favicon，否则每开一页控制台多一条 404，真错误反而被淹 |

### 顺带修掉的后端问题（同一批提交）

这些不是 UI 改造带来的，是这一轮顺手查出来的真实缺陷，每个都配了回归测试：

| 位置 | 修之前会怎样 |
|---|---|
| `api/routes/approve.py` `mark_executed` | 放行 `proposed` 标已改 —— 等于绕过「主人打钩」这道唯一人工闸门 |
| `api/routes/approve.py` `_close_exec_items` | 按 `decision_id` 一刀切，会把已取消单里的同条目也标 `executed_at`，作废单凭空多「已改」记录 |
| `api/db.py` `connect(readonly)` | 只读句柄上执行 `pragma journal_mode=WAL`（写操作），非 WAL 副本会抛 `attempt to write a readonly database`；平时不显形，换机器才炸 |
| `agents/attribute.py` `peers()` | 对照组没排除「同对象期间另有已执行决策」的候选 —— 别人的动作造成的变化被当成趋势扣掉 |
| `agents/attribute.py` | 新增 `ATTR_SETTLE_LAG_DAYS = 3`：窗一到就算账会把后窗订单系统性低估 → ACOS 虚高 → 判 worsened → 去踩刹车 |
| `agents/attribute.py` / `api/selftest.py` | 预算类动作归因窗 3 → 5 天：3 天里有一天是半截数据 |
| `api/routes/cockpit.py` | 归因面板按 `attribution_due_at`（窗口最后一天）判逾期，会三天假红；改按 `due + ATTR_SETTLE_LAG_DAYS` |
| `ingest/jijia_client.py` | token 过期重试是死代码（HTTP 200 但业务码 401/40005 没人接）；且重试复用 60s 主节流，一次过期阻塞一分钟 |
| `engine/facts.py` | `imp and ck / imp` 在 `imp=0` 时返回 `0` 而不是 `None`，把「没曝光」和「CTR 0%」混为一谈 |
| `adsdesk/chain.py` + `midship/` | `midship` 接进链但 **opt-in**：它的输入是当天事件账本，整链跑完前账本没闭合；完成判定读 `run_log` 而非 `chain_run`（后者是先复验后 record，第一次成功也必判 failed） |
