## 一、沉淀表

`schema_v2.sql` 需补齐以下 8 张表。

```sql
CREATE TABLE IF NOT EXISTS policy (
    policy_id      INTEGER PRIMARY KEY AUTOINCREMENT,
    scope          TEXT NOT NULL,          -- object | family | account
    object_id      TEXT NOT NULL,
    policy_type    TEXT NOT NULL,          -- allow_loss/defend/position_hold/cold_start/
                                           -- clearance/strategic/freeze/tos_protect/
                                           -- tos_defend/competitor_bid/price_match/
                                           -- no_match/test_period/stock_risk/account_block
    params_json    TEXT,                   -- 如 {"acos_cap":0.6,"monthly_loss_cap":200}
    source         TEXT NOT NULL,          -- 主人原话 | agent推断
    evidence_text  TEXT,                   -- 打钩时填的依据
    status         TEXT NOT NULL DEFAULT 'active',  -- active|verified|refuted|expired
    created_at     TEXT NOT NULL,
    expires_at     TEXT,                   -- 阻塞类必填
    reviewed_at    TEXT
);

CREATE TABLE IF NOT EXISTS param_override (
    override_id    INTEGER PRIMARY KEY AUTOINCREMENT,
    scope          TEXT NOT NULL,
    object_id      TEXT NOT NULL,
    param_key      TEXT NOT NULL,          -- target_acos/account_daily_budget/window_days...
    param_value    TEXT NOT NULL,
    source         TEXT NOT NULL,
    evidence_text  TEXT,
    created_at     TEXT NOT NULL,
    expires_at     TEXT                    -- 季度复核
);

CREATE TABLE IF NOT EXISTS observation_task (
    task_id        INTEGER PRIMARY KEY AUTOINCREMENT,
    object_id      TEXT NOT NULL,
    reason_code    TEXT NOT NULL,
    hypothesis     TEXT NOT NULL,          -- 「假设：这是季节性淡季」
    metric         TEXT NOT NULL,          -- 看什么指标
    judge_rule     TEXT NOT NULL,          -- 到期怎么判成立/不成立
    created_at     TEXT NOT NULL,
    due_at         TEXT NOT NULL,
    result         TEXT,                   -- verified | refuted | inconclusive
    resolved_at    TEXT
);

CREATE TABLE IF NOT EXISTS experiment (
    experiment_id  INTEGER PRIMARY KEY AUTOINCREMENT,
    object_id      TEXT NOT NULL,
    reason_code    TEXT NOT NULL,
    hypothesis     TEXT NOT NULL,
    change_json    TEXT NOT NULL,          -- 改什么
    control_json   TEXT NOT NULL,          -- 对照组是谁
    metric         TEXT NOT NULL,
    created_at     TEXT NOT NULL,
    ends_at        TEXT NOT NULL,
    result         TEXT,
    evidence_level TEXT                    -- 强|中|弱（弱不进 policy）
);

CREATE TABLE IF NOT EXISTS reason_hit (
    hit_id         INTEGER PRIMARY KEY AUTOINCREMENT,
    object_id      TEXT NOT NULL,
    reason_code    TEXT NOT NULL,          -- Q01-A1 这种
    scope          TEXT NOT NULL,
    evidence_text  TEXT,
    created_at     TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS reason_excluded (
    excluded_id    INTEGER PRIMARY KEY AUTOINCREMENT,
    object_id      TEXT NOT NULL,
    reason_code    TEXT NOT NULL,
    created_at     TEXT NOT NULL,
    expires_at     TEXT NOT NULL           -- created_at + 90 天
);

CREATE TABLE IF NOT EXISTS agent_assumption (
    assumption_id  INTEGER PRIMARY KEY AUTOINCREMENT,
    object_id      TEXT NOT NULL,
    question_code  TEXT NOT NULL,          -- Q01
    default_action TEXT NOT NULL,          -- 跳过时采用的默认项
    created_at     TEXT NOT NULL,
    review_at      TEXT NOT NULL,
    result         TEXT                    -- verified | refuted
);

CREATE TABLE IF NOT EXISTS competitor_watchlist (
    asin           TEXT PRIMARY KEY,
    label          TEXT,
    watch_dims     TEXT NOT NULL,          -- price,bsr,rating,promo
    thresholds_json TEXT,                  -- {"price_drop":0.05,"bsr_move":0.30}
    active         INTEGER NOT NULL DEFAULT 1,
    created_at     TEXT NOT NULL
);
```

`decision_log` / ticket 需加字段：`checked_at`、`checked_by`、`reject_reason`、`reject_reason_code`。没有「打钩」落点，决策层交互无处记录。

## 二、需要的函数

| 函数 | 位置 | 作用 |
|---|---|---|
| `reason_triggers(conn, start, end)` | facts.py | 算 12 类触发条件，返回候选题 |
| `auto_verdicts(conn, start, end)` | facts.py | 算自动判定区（曝光/匹配集中度/归因窗口/库存/重复投放），产出诊断结论 |
| `structure_conflicts(conn, start, end)` | facts.py | Q13：同词跨活动、词族归并 |
| `policy_gate(object_id, policy)` | 新增 gate.py | 前置闸：被 policy 保护的对象不产生建议 |
| `dedupe_by_reason(conn, candidates)` | 新增 gate.py | 查 reason_hit / reason_excluded 去重 |
| `render_questions(candidates)` | 新增 report.py | 按「影响金额 × 不确定性」排序取前 5，渲染打钩表 |
| `apply_answers(conn, answers)` | 新增 report.py | 打钩/划掉/跳过 → 写对应表 |

词典下一步仍是：转成 `engine/reasons_v1.yaml`（程序可读），再补上述函数与表。本说明不代替代码改动。

## 三、报告模板

现在只有建议表，需要补疑问和诊断区块：

```
一、账户状况
二、结构问题（Q13，不出题）
三、自动诊断（数/外 类结论）
四、需要你回答的 N 个问题（≤5），打钩表
五、今天该做什么（≤8 条建议）
六、每条建议是怎么算出来的
```

Q13 结构问题区块示例：

```
结构问题：N 个词在多个活动重复投放，占关键词花费 X%
   - 词 A 在 4 个活动，$… / … 点击 / … 单
   - 词 B 在 2 个活动，$… / … 点击 / … 单
   建议：先做活动归并，再谈降 bid——否则降一个涨一个。
```
