# 事件与派单规则 v0.1

- 日期：2026-11-16 Asia/Shanghai
- 依据：计划书 v1.1 待拍板第 5 条已定
- 范围：格式与规则。2026-11-16 已接上：ingest / engine 收尾写 event_inbox，中台 midship 只消费、去重、派单、留痕。不改启动器、不新建调度器。待送达进 tell_outbox，由船长送到本聊天。

## 一、事件格式

全部事件进本机 `event_inbox` 表。字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| writer | 是 | 写入方：`ingest` / `engine` / `sorftime` / `captain` |
| source | 是 | 来源系统，如 `ads-ingest`、`ads-engine`、`sorftime`、`cs` |
| type | 是 | 见下面的类型表 |
| object_id | 是 | 默认 `B0GLYW51HY` |
| summary | 是 | 一句话，够判断、够去重 |
| backlink | 否 | 回到日志、报告或会话的路径 |
| occurred_at | 是 | 事件发生时间，带 +08:00 |
| received_at | 是 | 写入中台的时间 |
| dedupe_key | 是 | 同一件事只留一条，建议 `type|object_id|业务日或对象键` |
| payload_json | 否 | 原始细节，不进摘要 |
| status | 是 | `pending` / `consumed` / `ignored` |

中台只轮询 `status=pending` 的行，不自己定时去拉积加。

## 二、第一批规则

```yaml
rules:
  - name: ingest_done
    when: { type: ingest.done, writer: ingest }
    to: midship
    action: consume
    tell: silent
    note: 只标记数据已到，等 engine.done 再出奏折

  - name: engine_done
    when: { type: engine.done, writer: engine }
    to: captain
    action: pack_memorial
    tell: chat
    note: 每日奏折送到本聊天；同一业务日只出一张

  - name: competitor_move
    when: { type: [competitor.price_drop, competitor.promo, competitor.bsr_move], writer: sorftime }
    to: pirate_and_captain
    action: maybe_memorial_q10
    tell: memorial_if_needed
    note: 进奏折旁证或 Q10，不单独刷屏

  - name: aba_weekly
    when: { type: aba.weekly, writer: sorftime }
    to: analyst
    action: weekly_context
    tell: memorial_if_needed

  - name: inventory_anomaly
    when: { type: inventory.anomaly, writer: captain }
    to: supply_and_ads
    action: freeze_candidate
    tell: memorial
    note: 广告层只出冻结候选，不写后台

  - name: cs_thread_new
    when: { type: cs.thread.new, writer: captain }
    to: assistant
    action: handle_thread
    tell: silent
    note: 不进广告奏折

  - name: memorial_unapproved
    when: { type: memorial.unapproved.due, writer: captain }
    to: captain
    action: remind
    tell: chat
    note: 奏折到期未批，同一张不重复催
```

同一 `dedupe_key` 已存在则不再插入。同一对象、同一类型，同时只消费一轮。
