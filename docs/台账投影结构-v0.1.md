# 台账投影结构 v0.1

- 日期：2026-11-16 Asia/Shanghai
- 依据：计划书 v1.1 待拍板第 1 条已定
- 单一写入点在本机 SQLite。gbrain 只做每日只读投影，不承担写入。

## 一、哪类决定写哪张表

| 种类 | 写入表 | 说明 |
|---|---|---|
| 建议与审批 | `decision_log` | 含打钩、拒绝理由、执行与 7/14 日结果 |
| 定的事（策略） | `policy` | 主人原话或已验证的策略，带作用域和到期日 |
| 参数校准 | `param_override` | 如目标 ACOS、日预算 |
| 定了不做 / 显式排除 | `reason_excluded` | 90 天到期 |
| 观察中的假设 | `observation_task`、`agent_assumption` | 到期用数据验 |
| 实验 | `experiment` | 必须带对照说明；弱证据不回写 `policy` |

## 二、gbrain 投影

每日引擎跑完、奏折处理之后，导出到 `gbrain/memory/decisions/`（只读，覆盖写当日文件，不改历史原件）：

- `家洛定的事.md`：来自 `policy` 中 `status=active`，保留原话、日期、作用域、到期日
- `定了不做的事.md`：来自 `reason_excluded` 以及带 `reject_reason` 的否决
- `当日审批摘要.md`：当日 `decision_log` 中已勾或已拒的条目

投影失败不得回写数据库。本机 `docs/` 不是写入点，只放结构说明。
